# Data Logging

Record trajectories, commands and real velocities, then save/load/plot them.
Collisions (robot–robot, robot–obstacle, robot–grid) are recorded as timestamped
events.

!!! tip "Guide"
    See [Data Logging & Analysis](../logging.md) for a practical walkthrough of
    saving/exporting a log and an example of the saved files.
